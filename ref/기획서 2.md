# 기획서 2: Claude Code 연동

Oct 12, 2026 · @쭌

## 개요

VSCode의 Claude Code를 채팅창으로 사용합니다. 보정은 py 스크립트가 Mac에서 로컬로 하고, 대화와 보정값 판단은 Claude Code가 맡습니다. 스크립트 안에는 API 연동이나 로컬 LLM을 넣지 않습니다.

| 역할 | 담당 |
| --- | --- |
| 보정 연산 (디코딩, 톤, AI 노이즈 제거, 피부, LUT, export) | py 스크립트, Mac 로컬 |
| 사진 분석, 보정값 결정, 재조정 | Claude Code |
| 원하는 느낌 지시, 최종 확인 | 사용자 |

기획서 1의 파이프라인, 프리셋, 크롭, 로컬 AI 보정은 그대로 유지합니다.

## 작동 흐름

원하는 느낌이 나올 때까지 edit.json 수정과 미리보기를 반복하고, 만족하면 같은 값으로 최종 export합니다.

## 스크립트 추가 사항

Claude Code가 사진을 이해하고 값을 바꿔가며 재실행할 수 있도록 옵션 세 개를 추가합니다.

| 옵션 | 역할 |
| --- | --- |
| `--info` | EXIF, ISO, 화이트밸런스, 히스토그램 요약, 얼굴 위치를 JSON으로 출력 |
| `--preview` | 긴 변 1024px 미리보기 JPEG를 `previews/`에 저장. Claude Code는 원본 대신 이 파일을 봄 |
| `--params edit.json` | 보정값을 JSON 파일로 받음. Claude Code는 이 파일만 고치고 재실행 |

`edit.json` 예시 (항목 이름은 라이트룸 방식 프리셋과 같음):

```json
{
  "file": "DSC_1236.NEF",
  "preset": "portrait",
  "exposure": 0.4,
  "shadows": 20,
  "temperature": 5400,
  "skin": {"brightness": 10, "smooth": 15},
  "lut": {"file": "luts/film.cube", "strength": 50},
  "crop": "4:5",
  "rotate": 0.8
}
```

## CLAUDE.md와 /edit 명령

프로젝트 루트의 `CLAUDE.md`에 스크립트 사용 규칙을 적어두면, Claude Code가 매번 설명 없이도 같은 방식으로 작업합니다.

**`CLAUDE.md`에 넣을 내용**

- 실행 명령과 옵션 목록 (`--info`, `--preview`, `--params`, `--preset`, `--size`)
- `edit.json` 항목별 값 범위 (예: 노출 −5\~+5, 하이라이트 −100\~+100)
- 작업 순서: `--info` 확인 → `edit.json` 작성 → `--preview`로 실행 → 미리보기 확인 → 최종 export
- 규칙: 원본 NEF는 수정하지 않음, 미리보기만 열람, 한 번에 바꾸는 항목은 요청한 것 위주
- 프리셋 저장 위치와 이름 규칙 (`presets/*.yaml`)

**`/edit` 명령 (선택)**

`.claude/commands/edit.md`에 위 작업 순서를 적어두면 `/edit DSC_1236 피부 화사하게`처럼 짧게 요청할 수 있습니다.

## 사용 예시

VSCode의 Claude Code 패널에서 이렇게 대화합니다.

```
나: 0901 폴더 사진들 인물 프리셋으로 정리해줘
Claude: --info로 24장 확인, ISO 6400 이상 5장은 AI 노이즈 제거를 켰어요.
        미리보기 24장 생성했습니다.

나: DSC_1236 좀 어둡고 피부가 칙칙해
Claude: 노출 +0.4, 섀도 +20, 피부 밝기 +10으로 바꿨어요. 미리보기 확인해 보세요.

나: 좋아, 필름 느낌 조금 더. 그리고 4:5로 잘라줘
Claude: LUT 강도 30% → 50%, 4:5 크롭 적용했어요.

나: 이 설정 my_film 프리셋으로 저장하고 전부 2048px로 export
Claude: presets/my_film.yaml 저장, 24장 export 완료
```

## 개발 단계와 주의사항

기획서 1의 개발 순서에서 Claude Code 연동에 필요한 옵션을 MVP 바로 다음으로 당깁니다.

1. **MVP**: 디코딩 → 회전·크롭 → JPEG export
2. **연동 기반**: `--info`, `--preview`, `--params`, `CLAUDE.md` 작성
3. **일괄 처리**: 폴더 입력, 사진별 설정, 우선순위
4. **톤과 프리셋**: `tone.py`, YAML 프리셋, `.xmp` 파서
5. **색감**: LUT, 디테일, 렌즈 보정
6. **로컬 AI**: 얼굴·피부 보정 → 원클릭 자동 → AI 노이즈 제거
7. **편의**: `/edit` 명령

**주의사항**

- 보정 연산은 로컬이지만 Claude Code와의 대화는 인터넷이 필요하고, Claude 요금제 사용량에 포함됩니다.
- 사진을 많이 볼수록 사용량이 늘어나므로 Claude Code에는 1024px 미리보기만 보여줍니다.
- Claude Code가 원본 NEF와 결과 파일을 지우지 않도록 `CLAUDE.md`에 규칙을 명시합니다.
